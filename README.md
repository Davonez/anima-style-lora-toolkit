# Anima 画风 LoRA 工具包

给「画风 LoRA」用的 **标注清洗 + 数据集量化体检 + 出图对照**，外加一份可直接用的
**Next-Trainer 训练预设**。Windows / PowerShell 5.1+ / 双击即用 / 零第三方依赖。

---

## 它解决什么问题

一句结论：

> **风格 LoRA 学不到画风，通常不是模型容量不够，而是标注在替模型解释画风。**

把光照、明暗、色彩分级、渲染方式、风格流派词写进 caption，等于告诉模型
「这些不用你学，读文字就行」——它只会剩下装饰词汇。这个工具包做的事是：

1. **把「替模型解释画风」的词从标注里删掉**（约 250 个词，分 5 类）；
2. **把数据集本身量出来**：多少张近黑白、平均饱和度多少、姿势标了几成；
3. **把「像不像」变成数字**：亮度（两个口径）、饱和度、同 seed 像素差；
4. **排掉一个改完标注却完全不生效的坑**：文本编码器缓存不比对 caption。

## 三个工具

| 工具 | 入口 | 作用 |
|---|---|---|
| 标注清洗器 | `一键清洗.bat` / `一键预览.bat` | 删画风泄漏词、去重、合并冲突、统一触发词与口径，并按「只写内容」的口径重排；顺带体检 |
| 出图对照 | `一键对照.bat` | 两组图的亮度/饱和/像素差对照，判断「这版比上版更像吗」 |
| 训练预设 | `安装预设.bat` | 把 `rank32/alpha64` 的 Anima 画风预设装进 Next-Trainer |

## 快速开始

1. 解压到任意目录（路径里有中文没问题）。
2. **先预演**：双击 `一键预览.bat` → 选数据集目录（图片 + 同名 txt 所在目录）→ 输入触发词（如 `@myartist`）。
   它只会生成报告，**不动任何文件**。
3. 看 `_tag备份\<数据集名>_<时间>\` 下的报告（见下），决定要不要改规则。
4. **确认写盘**：双击 `一键清洗.bat`，流程同上，最后输入 `y`。原 txt 自动备份到同一目录。
5. 出图后：双击 `一键对照.bat`，选 A 组（训练原图或零权重出图）和 B 组（挂 LoRA 的出图）。

> 训练过 Anima 的话，清洗完记得让工具把 `*_anima_te.npz` 挪走——它不会自动失效（详见下文）。

## 清洗器做什么

- **画风泄漏词**（核心）：媒介/笔触、光照/明暗、色彩分级、风格流派、主观修饰，5 类约 250 词。
  唯一例外是「彩色/黑白」那一组：数据集里近黑白图 ≥5% 时**保留**，否则删——详见 `docs/说明.md`。
- **数据集体检**：覆盖度、景别/姿势/表情/背景分布（「换个动作就崩」的根源）、语言统计、标注形态（tag 还是句子）、互斥冲突。
- **图片色彩实测**：抽样看每张的亮度（luma709 与通道均值两个口径）、饱和度、近灰像素占比。
- **训练缓存排雷**：检出 `*_anima_te.npz` 并提示挪走。
- **常规清洗**：元数据/版权/质量词/评分/签名、加权语法 `(tag:1.2)`/`((tag))`/`[tag]`、全角逗号、
  下划线归一、父子蕴含、颜色冲突合并、触发词统一到第一位、按 Anima 顺序排序、GBK 自动转码。

## 报告长什么样

写在**数据集父目录**的 `_tag备份\<数据集名>_<时间>\`（不进数据集，训练器读不到）：

| 文件 | 内容 |
|---|---|
| `数据集体检.md` | 规模、色彩实测、覆盖度、景别/姿势分布、语言、疑似问题、缓存排雷、训练配置体检 |
| `清洗报告.md` | 删除分类统计、画风泄漏词清单、逐文件明细 |
| `待复核.txt` | 疑似角色名/作品名/误标生词、近黑白图清单、缺图缺标注 |
| `评测提示词.txt` | 中立测试提示词 + 负向词 + 出图纪律 |
| `标注规范.md` | 写什么 / 禁写什么 |
| `tag全量表.md` | 全量 tag 覆盖度表 |

## 训练预设

`安装预设.bat` → 选你的 Next-Trainer 目录 → 装进 `config\presets\`。
之后在 Anima DiT / Kohya-ss / LoRA 页面 → 工具栏「训练预设」里选它。

预设要点：`dim 32 / alpha 64`（缩放 2.0，出图权重 0.4~0.6 就够）、10 轮、`keep_tokens=1`、
缓存 latent + 文本编码器、`prefer_json_caption=false`。为什么这样配、步数怎么换算、
换数据集后轮数怎么改，见 [`docs/训练预设.md`](docs/训练预设.md)。

## 环境

- Windows 10/11 + **PowerShell 5.1**（系统自带）或 7.x；
- 不需要 Python、不需要装依赖；
- 图片测量用 .NET 自带的 `System.Drawing`；
- 只认 Anima/danbooru 风格的 tag 标注（空格分隔的 tag 列表）。如果你的 tagger 输出自然语言句子，
  工具会**红色警告**「tag 级规则会失灵」，这时只能手工处理。

## 已知限制

- 只做「删 + 排 + 归一」，**不会凭空补 tag**；
- 不会自动判断哪些是角色名——它给你一份「无内容词 + 低频」的候选清单，确认后贴进 `自定义_额外删除.txt`；
- 近黑白/低饱和是数据集属性，工具只能量出来告诉你，改不了；
- 训练缓存的判定依据是读源码得到的（`strategy_anima.py` 只查键名、不比对 caption），
  其他训练器/版本可能不同。
