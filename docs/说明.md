# 说明 —— 标注清洗器与对照工具

> 一句话原则：**只写「画面里有什么」，不写「它看起来怎样」——看起来怎样，正是要让 LoRA 去学的东西。**

---

## 一、为什么只删「垃圾 tag」不够

大多数清洗脚本做的是：删元数据、删质量词、删水印、去重、排序。这些都对，但漏掉了真正让画风学不像的那一类词：

> **把光照、明暗、色彩分级、渲染方式、风格流派写进 caption，等于告诉模型「这些不用你学」。**

一旦 caption 里写了 `soft backlighting` / `high contrast` / `watercolor (medium)` / `cel shading`，
模型就有了一条捷径：这些观感读文字就够了，不需要从图里学。它于是只学会「蕾丝、纸牌、蝴蝶」这类装饰名词，
整幅画的明暗、色彩、笔触全部留在底模的默认状态。

所以本工具的第一优先级不是「删垃圾」，而是**删掉替模型解释画风的词**。

## 二、三种用法

| 方式 | 操作 |
|---|---|
| 双击清洗 | 双击 `一键清洗.bat` → 弹文件夹选择框 → 选数据集目录 → 输入触发词 → 预演 → 输 `y` 写盘 |
| 拖拽 | 把数据集文件夹拖到 `一键清洗.bat` 图标上 |
| 只看不改 | 双击 `一键预览.bat`（等于加 `-DryRun`） |
| 命令行 | `powershell -NoProfile -ExecutionPolicy Bypass -File "AnimaTagCleaner.ps1" -Folder "D:\datasets\my_artist" -Trigger "@myartist"` |

写盘时发生什么：

1. 原 txt 全部备份到**数据集父目录**的 `_tag备份\<数据集名>_<时间>\txt_原文件\`（不进数据集，避免训练器误读）；
2. 生成 6 个报告（见第四节）；
3. 如果目录里有 `*_anima_te.npz`，会问你要不要挪走——**建议一律挪走**，理由见第三节第 4 条。

还原：把 `txt_原文件\` 里的文件拷回数据集即可，没有别的状态需要还原。

## 三、自动做什么

### 1. 删画风泄漏词（核心）

内置 5 类约 250 个词，删掉并在报告里逐条列出：

| 类别 | 例子 |
|---|---|
| 媒介/笔触 | `watercolor (medium)`、`oil painting (medium)`、`cel shading`、`flat color`、`lineart`、`sketch`、`anime`、`realistic`、`impasto` |
| 光照/明暗 | `backlighting`、`rim lighting`、`soft lighting`、`cinematic lighting`、`high contrast`、`shadow`、`silhouette`、`chiaroscuro`、`lens flare`、`bloom` |
| 色彩分级 | `saturation`、`desaturated`、`color grading`、`vibrant colors`、`muted colors`、`gradient`、`monochromatic` |
| 风格流派 | `style`、`art style`、`ukiyo-e`、`art nouveau`、`impressionism`、`chibi`、`retro`、`vaporwave` |
| 主观修饰 | `beautiful`、`cute`、`dreamy`、`atmospheric`、`detailed background`、`expressive` |

**唯一例外是「彩色/黑白」这一类**（`monochrome`、`greyscale`、`limited palette`、`spot color`、`sepia`）。
它不是纯泄漏，而是「这张是黑白还是彩色」的区分信息：

- 数据集里近黑白图 <5% → 当泄漏词删掉；
- ≥5% → **保留**，因为删了模型就没法区分彩色/黑白，会把两种画风混成一锅（这是「出图发黑白」的一个来源）。

体检报告会写清当前是哪种情况，以及到底有几张近黑白图。

### 2. 数据集级体检

- 覆盖度：全数据集都有的 tag、只出现 1 次的 tag、稀有 tag（全量写进 `tag全量表.md`）；
- **景别 / 姿势 / 表情 / 背景的覆盖率和分布** —— 「换个动作就崩」的根源：
  姿势标注只覆盖一半时，模型学不到「文字↔动作」的对应，换动作只能瞎猜；
- 语言统计：中文/日文 tag 有几个（跨语言会显著削弱 LoRA）；
- 标注形态：平均每段几个词 —— 检出是自然语言句子时**红色警告** tag 级规则会失灵；
- 互斥冲突：同一张图标了 `standing` + `sitting`、`1girl` + `2boys`、`black hair` + `blonde hair` 之类，
  按「保留第一个（置信度最高）」处理并记进报告。

### 3. 图片色彩实测

不只看 txt，直接抽样最多 160 张图，量每张的：

- **平均亮度 luma709** 和 **通道均值**（两个口径都出——两者能差几十点，不能混用）；
- **平均饱和度**（0–1，对风格最敏感）；
- **近灰像素占比**（>80% 基本就是黑白图）。

低于 0.08 饱和的会单独列成清单，让你决定「这算画风的一部分，还是该从数据集里剔掉」。

### 4. 训练缓存排雷（最容易忽略，也最致命）

Anima 管线开 `cache_text_encoder_outputs = true` 时，磁盘上会留 `*_anima_te.npz`。
这类缓存的校验（参考 `sd-scripts/library/strategy_anima.py` 的 `is_disk_cached_outputs_expected()`）
**只检查 npz 里有没有 `prompt_embeds` / `attn_mask` / `t5_input_ids` 等键，不比对 caption**。

也就是说：改了 txt、又用同一个目录重训，训练器可能继续吃旧 caption 的 embedding——
**清洗等于没做，而且很难查出来**。所以清洗完把 `_anima_te.npz` 挪走（工具会问，挪到备份目录，训练时自动重建，只损失几分钟编码时间）。

`*_anima.npz`（潜变量缓存）只跟图片/分辨率有关，不用动。

### 5. 训练配置体检（可选）

用 `-TrainConfig` 指定一份 Next-Trainer 的 toml；不给时会自动在
`%NEXT_TRAINER_HOME%\config`、数据集父目录、脚本目录里找同名数据集的配置。
检查：

- `network_alpha / network_dim`：**<1.0 会告警**。缩放 0.5 = 学到的增量被砍半，出图只能靠把权重往上拉补偿；
  权重一高，构图和动作就开始崩。
- `keep_tokens` 是否为 1（触发词被钉在第一位）；
- 轮数 × 图数 是否落在过训练区（小数据集 30 轮以上容易脸崩、底色发灰）。

### 6. 常规清洗

- 元数据/平台/来源/meme、版权与系列名、质量词、`score_N`、签名水印；
- **画面内文字保留**（`text`、`speech bubble` 这类算内容，要 `-DropAllText` 才删）；
- 加权语法全拆：`(long hair:1.2)`、`((tag))`、`[tag]`、`{tag}`、`<lora:x:1>`；
- `\(` 转义还原、全角逗号/顿号/竖线分隔、下划线归一（`long_hair` → `long hair`，表情 tag 不会拆坏）；
- 父子蕴含（有 `white shirt` 删 `shirt`）、修饰语前缀、同义组、颜色冲突合并（多角色图自动跳过）；
- 触发词统一成 `@xxx` 放第一位，其它 `@画师` tag 顶掉；
- 按 Anima 官方顺序排序；UTF-8 无 BOM 写回，GBK 文件自动转码并提示。

## 四、报告在哪、怎么读

写在**数据集父目录**的 `_tag备份\<数据集名>_<时间>\` 下：

| 文件 | 先看哪 | 内容 |
|---|---|---|
| `数据集体检.md` | ★先看 | 规模、色彩实测、覆盖度、景别/姿势分布、语言、疑似问题、缓存排雷、配置体检 |
| `清洗报告.md` | | 删除分类统计、画风泄漏词清单（逐条）、逐文件明细 |
| `待复核.txt` | ★人工过一遍 | 疑似角色名/作品名/误标生词（有误报）、近黑白图清单、缺图缺标注 |
| `评测提示词.txt` | ★出图前看 | 中立测试提示词 + 负向词 + 出图纪律 |
| `标注规范.md` | | 写什么 / 禁写什么 |
| `tag全量表.md` | | 全量 tag 覆盖度表（排查口径不一致用） |

典型工作流：

```
1. 一键预览.bat                 ← 看会删什么，不写盘
2. 看 待复核.txt A 段           ← 有角色名就贴进 自定义_额外删除.txt
3. 一键清洗.bat                 ← 确认写盘 + 挪走旧缓存
4. 看 数据集体检.md             ← 色彩实测 / 姿势覆盖 / 缓存 / alpha
5. 按 评测提示词.txt 出对照图
6. 一键对照.bat                 ← 量出图 vs 训练原图的亮度/饱和/像素差
```

## 五、两个常见症状怎么查

### 症状 A：出图发黑白 / 发灰

1. **数据集本身灰不灰**（体检 §2）。实测过的例子：一套 34 张的粉彩画风集，平均 luma709 **0.736**、
   饱和 **0.133**、近黑白 3 张（9%）、低饱和 18 张 —— 这本身就是低饱和数据集，出图发灰是「学到了」，不是 bug。
2. **标注里有没有 `monochrome` 这类词**（清洗报告第二节）。有近黑白图时工具会自动保留。
3. **出图到底比谁灰**（`一键对照.bat`）。同一 prompt、同一 seed 对照「无 LoRA 底模」与「挂 LoRA」：
   如果挂上后饱和明显下降、亮度上升，说明 LoRA 把底模的色彩洗掉了——那是「数据集低饱和 + 权重过高 + 过训练」
   叠加的结果，不是提示词问题。
4. 处置顺序：先把 `alpha` 提到 `dim` 的 1.5~2 倍（出图权重就能降下来），再试负向词
   `monochrome, greyscale, greyscale with colored background, limited palette, spot color, sepia`，
   最后才考虑「往数据集里补彩色图 / 剔掉近黑白图」。

### 症状 B：人物动作错误

1. **姿势标注覆盖率**（体检 §4）：覆盖率低 = 模型学不到「文字↔动作」的对应；
2. **互斥 tag**（清洗报告逐文件明细的备注栏）：同一张图里 `standing` + `bent over`、`1girl` + `2boys`，
   等于给模型互相矛盾的监督信号；
3. **景别单一**（体检 §4）：如果 80% 的图都是 `upper body`，风格就被绑在胸像构图上；
4. **缩放比**（配置体检）：`alpha/rank = 0.5` 时出图权重被迫拉到 0.8~1.0，结构先崩；
5. **过训练**：小数据集 30+ 轮后脸和动作一起崩，取 60%–100% 之间的存档。

## 六、开关

| 开关 | 作用 |
|---|---|
| `-Trigger @xxx` | 统一画风触发词，强制放第一位，其它 `@画师` tag 被替换 |
| `-DryRun` | 只出报告，绝不改文件 |
| `-Yes` | 跳过确认（脚本化用） |
| `-Recurse` | 连子文件夹一起处理（报告里用相对路径） |
| `-TrainConfig <toml>` | 指定训练配置做体检（不给就自动找同名配置） |
| `-CleanCache` | 不询问，直接把失效的 `_anima_te.npz` 挪走 |
| `-KeepCache` | 不询问，保留缓存（**会导致清洗不生效**） |
| `-SkipImageScan` | 不做图片色彩实测（大目录想跑快一点） |
| `-DropTags "a,b"` | 临时额外删除指定 tag |
| `-DropCJK` | 删掉中文/日文 tag（编码器主语言是英文时用） |
| `-MaxTags <n>` | 单图 tag 上限（默认不限；触发词不计） |
| `-KeepLighting` / `-KeepMedium` | 保留光照 / 媒介类 tag（不推荐） |
| `-KeepColorTreatment` | 强制保留 monochrome 这类词 |
| `-KeepSignature` | 保留 signature / watermark / artist name |
| `-DropAllText` | 连画面内文字 tag 一起删 |
| `-KeepPose` | 不做姿势/景别互斥合并 |
| `-KeepHairColor` / `-KeepEyeColor` | 不合并发色 / 瞳色（角色本来就是渐变、异色时用） |
| `-KeepParensEscape` | 保留 `\( \)` 转义写法 |
| `-NoSort` / `-NoLowercase` | 不重排顺序 / 不转小写 |
| `-Extensions ".txt,.caption"` | 要处理的标注后缀 |
| `-BackupRoot <dir>` | 备份/报告根目录（默认数据集父目录下的 `_tag备份`） |
| `-ConfigDir <dir>` | 自定义黑白名单所在目录（默认脚本所在目录） |

## 七、对照工具（`一键对照.bat`）

- **两个口径的亮度**：luma709（0.2126R+0.7152G+0.0722B）和通道均值，报告里写清用的是哪个；
- **平均饱和度**、**近灰像素占比**、**近黑白图张数**；
- **同尺寸缩略图像素差**（32×32 平均绝对差 /255）——只衡量风格与色调差，不是贴合度；
- 自动按文件名配对；名字对不上就按排序逐位配对并提示。

用法：双击 → 选 A 组（训练原图 或 零权重出图）→ 选 B 组（挂 LoRA 的出图）→ 报告落在 A 的父目录。
只想体检一个目录就取消第二个选择框。

```
powershell -NoProfile -ExecutionPolicy Bypass -File "StyleCompare.ps1" `
    -A "D:\datasets\my_artist\originals" -B "D:\datasets\my_artist\gen_w0.8"
```

## 八、实测样例（两套真实数据集）

| 数据集 | 文件 | tag | 删除 | 近黑白图 | 平均饱和 |
|---|---|---|---|---|---|
| 画师 A（已清洗过一轮，34 张） | 34 | 884 → 879 | 5 | 3（9%） | 0.133 |
| 画师 B（原始标注，38 张） | 38 | 1250 → 1119 | 169 | 0 | 0.224 |

边界用例（构造数据集）全部通过：`(tag:1.2)` / `((tag))` / `[tag]` / `<lora:>`、全角逗号、顿号、竖线分隔、
`long_hair`、`^_^`/`:d` 表情、空文件、GBK 文件、中文 tag、重复 tag、父子蕴含、发色互斥、多角色跳过合并、
`score_9`、`signature`、纯符号垃圾、自然语言句子（红色警告）、文件名对不上、缺图缺标注。

## 九、注意事项

- **训练中不要跑**。训练器会在数据集目录写 `*_anima.npz` / `*_anima_te.npz`，边训边改 txt 容易对不上。
- 备份和报告**不在数据集目录里**（在父目录的 `_tag备份`），不会被训练器当成标注或图片读进去。
- 只做「删 + 排 + 归一」，**不会凭空补 tag**。
- 想改内置规则：编辑 `AnimaTagCleaner.ps1` 里的 `$LeakLight` / `$LeakMedium` / `$Implies` / `$GarmentNouns` 等表；
  只是加几个词，用 `自定义_画风词.txt` / `自定义_额外删除.txt` / `自定义_强制保留.txt` 就够了。
- `.ps1` 是 UTF-8 **带 BOM** 存的（Windows PowerShell 5.1 不认无 BOM 的中文脚本），改代码时别把 BOM 弄丢。
